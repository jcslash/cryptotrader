## 1. 現行規則（v1）的問題診斷

| # | 問題 | 為什麼造成「吃筍多、錯過多、賺得少」 |
|---|---|---|
| 1 | **倉位由 BTC 閘門決定，不由訊號品質決定**（0.25R / 0.5R） | 最佳訊號與最爛訊號下一樣大的注。最大單筆風險只有 0.5R，贏的時候賺不到什麼，輸的時候照扣手續費與滑價。與你「有信心就下大注」正好相反 |
| 2 | **停損位置沒定義**（"停損放哪裡"） | 名目＝虧損額÷停損%，停損不定，名目就不定。這是歧義，不是細節 |
| 3 | 「快速通道」只看量、成交額、離突破位距離 | 沒有看收盤位置、盤整質量、流動性；假突破（上影線、拉完即砸）照樣通過 |
| 4 | 一般點火要等確認棒，且 >8% 一律不做 | 真正強的幣在確認棒時已經跑掉，這是「錯過」的主因；同時沒有早期失敗退出，假突破要等到停損才走，這是「吃筍」的主因 |
| 5 | 1/3 在 +1.5R 出，之前沒有任何提前退出 | 假突破 100% 吃滿 -1R。沒有「3 根內收回突破位下方就走」「久攻不動就走」 |
| 6 | 每日 08:02 對漲幅榜前十對帳，且「每天最多調整一條規則」 | 與「滿 20 筆才檢討」**自相矛盾**；漲幅榜是事後諸葛（含不可能提前抓到的幣），每天改規則＝過擬合 |
| 7 | 「長上影線接著量縮」未定義門檻 | 無法執行，只能憑感覺 |
| 8 | 「同波只做最強一張」但沒定義「最強」 | 同上 |

## 2. v2 規則（全部可量化）

**1R = 帳戶權益 × 1%**（可調）。名目 = 願虧金額 ÷ 停損距離%。

### 2.1 訊號資格（每小時收盤判斷）
- 收盤 > 前 48 根 1H 最高價（突破位 L）
- 該根成交額 ≥ 前 48 根中位數的 5 倍
- 近 24h 成交額 ≥ 2,000 萬美元

### 2.2 評分（0–7，決定下多大注）
| 項目 | 分 |
|---|---|
| 量倍數 ≥10x / 5–10x | 2 / 1 |
| 收盤在該棒區間上 25% 且為陽線（無厚上影） | 1 |
| 收盤離 L ≤ 3% | 1 |
| 前 48h 區間寬 ≤ 20%（盤整後擴張） | 1 |
| 24h 成交額 ≥ 5,000 萬（流動性） | 1 |
| 7 日漲幅 ≤ 50%（非已拋物線） | 1 |

分級：**A ≥ 6　B = 4–5　C = 3　< 3 不做**。連兩根 ≥5x 且都收在 L 上 → 升一級（成交量持續＝信心）。

### 2.3 進場
- **A 級**：點火棒收盤立刻發卡（離 L ≤ 8%）。不等確認，解決「錯過」。
- **B / C 級**：等下一根確認棒（收在 L 上、量 ≥ 點火棒一半、離 L ≤ 8%；連續點火放寬到 12%）。
- 其餘＝追高不做，記錄原因。

### 2.4 停損（定義清楚）
停損 = max(點火/確認棒最低點, L − 1×ATR14(1H))，且至少離進場價 2%。停損距離 > 8% → **不做**（太延伸）。

### 2.5 倉位（信心決定大小）
| 級別 | 基礎風險 |
|---|---|
| A | 1.0R |
| B | 0.5R |
| C | 0.25R |

乘上 BTC 閘門係數：BTC 4H 收在 EMA20 上 **一根 ×0.5、連兩根以上 ×1.0**；未站上或當前 4H 正創新低 → **不發卡**。
總開倉風險上限 **2R**；停損已移到成本的單不佔風險額度（可滾動加新單）。同波多張時分數最高者先佔額度。

### 2.6 出場
1. **失敗退出**：進場後 3 根內任一根收盤回到 L 下方 → 市價出（假突破損失通常 < 1R）。
2. **時間停損**：12 根後最大浮盈仍 < 0.5R → 收盤出。
3. **+1.5R** 出 1/3，停損移到成本。
4. 剩下用**ATR 移動止損**：從最高點回落 `clamp(3×ATR%, 5%, 10%)`。不設固定止盈。

### 2.7 紀律（修正自相矛盾處）
- 每個訊號（DO / DON'T / WATCH）都寫入 `signals.csv`，附原因。
- 規則只在**每級別累積 ≥ 20 筆**後調整；每次只動一個參數，並用 `backtest.py` 前後半段都驗證。
- 08:02 漲幅榜對帳**只分類不改規則**：①規則擋掉（記錄擋在哪條）②當時無訊號資格 ③事後才漲、不可提前抓。只有 ① 累積到 20 例才進入檢討。
- 每 4 小時日誌：訊號數、做/不做、各級別未平倉風險、BTC 閘門狀態。

## 4. 怎麼判斷 v2 是否真的比 v1 好
`python3 backtest.py --days 120 --top 150`（同一份數據、同樣手續費 0.05% + 滑價 0.1%/邊）會輸出：
v1 vs v2 的 勝率 / 平均R / PF / 報酬 / 最大回撤 / **贏家事件召回率**（漏單）/ 前後半段（樣本外）/ A·B·C 分級期望值。
**判準**：A > B > C 的平均 R 在前後兩段都成立，才保留分級加碼；否則壓平倉位。v2 若在樣本外沒贏 v1，就是我錯了，改規則。

## 5. 已知限制
- 回測只含現在還在上市的幣（倖存者偏差，會讓結果偏樂觀）；未計資金費率；1H 內順序採悲觀假設（先停損）。
- 評分權重是先驗假設，未校準。90–120 天的樣本在單一市況，不能外推。
- 同波「最強」＝最高分；v1 對照組以時間先後取單，並非完全複製人工判斷。
